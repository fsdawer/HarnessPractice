# Notion 운영 가이드 — CutIng

## 워크스페이스 구조
- 메인 페이지: https://www.notion.so/367704f43e2e80098a5fc8833a250f44

## 페이지 네이밍 규칙
- 회의록: `[YYYY-MM-DD] 회의록 - [주제]`
- 기획서: `[기능명] 기획서 v[버전]`
- 스프린트: `Sprint [N] - [YYYY-MM-DD ~ YYYY-MM-DD]`

## 우선순위 태그
- 🔴 P0: 블로커 (오늘 해결)
- 🟠 P1: 주요 (이번 스프린트)
- 🟡 P2: 부가 (다음 스프린트)
- ⚪ P3: 아이디어 (백로그)

## 액션 아이템 형식
| 담당 | 작업 | 기한 | 상태 |
|------|------|------|------|
| 이름 | 내용 | MM-DD | 진행중/완료/대기 |

## notion-agent 호출 예시
```
"오늘 회의 내용 노션에 정리해줘: [회의 내용]"
"[기능명] 기획서 노션에 만들어줘"
"이번 스프린트 진행 상황 노션에 업데이트해줘"
```
