# CutIng 프로젝트 개요

## 핵심 문제
> "너무 많은 미용사, 미용실, 광고 속에서 나에게 잘 맞는 미용사를 찾기 어렵다"

사용자는 검색할 때 광고성 콘텐츠와 수많은 선택지에 압도되어 정작 자신의 취향과 상황에 맞는 미용사를 찾지 못한다.

## 핵심 가치 제안
**개인화된 미용사 매칭** — 광고 없이, 나의 위치·취향·예산에 맞는 미용사를 찾아주는 앱

## 타겟 사용자
- 이사·여행 등 새로운 지역에서 미용사를 처음 찾는 사람
- 기존 미용사에 불만족해 새로운 미용사를 찾는 사람
- 시술 종류(커트/펌/염색)별 전문가를 찾는 사람

## 핵심 기능 우선순위
| 순위 | 기능 | 이유 |
|-----|------|------|
| P0 | 내 주변 미용사 지도 탐색 | 위치 기반 개인화의 시작점 |
| P0 | 평점·리뷰 기반 랭킹 | 광고 없는 신뢰 지표 |
| P1 | 스타일리스트 상세 프로필 | 취향 매칭 판단 근거 |
| P1 | 실시간 예약 | 발견 → 예약 즉시 연결 |
| P2 | 채팅 | 시술 전 상담 |
| P2 | 커뮤니티 | 후기·정보 공유 |

## UX 원칙
1. **광고 없음** — 랭킹은 순수 평점·리뷰·예약 수 기반
2. **3탭 이내 예약** — 발견 → 상세 → 예약 완료
3. **신뢰 우선** — 리뷰·평점·거리 정보를 앞에 노출
4. **모바일 퍼스트** — 주요 사용 맥락은 외출 중 스마트폰

## 경쟁 서비스와 차별점
| 서비스 | 문제점 | CutIng 해결 |
|--------|--------|------------|
| 네이버 미용실 검색 | 광고 상위 노출 | 베이지안 랭킹(광고 없음) |
| 카카오헤어샵 | 대형 살롱 위주 | 프리랜서·소규모 포함 |
| 마메드네 | 정보 과다 | 핵심 정보만 간결하게 |
