# QA 가이드 — CutIng

## 테스트 환경
```bash
brew services start redis   # Redis 필수
./gradlew bootRun            # 백엔드 :8080
cd frontend && npm run dev   # 프론트 :5173
./gradlew test               # 전체 테스트
```

## 심각도 기준
| 심각도 | 기준 | 예시 |
|--------|------|------|
| Critical | 핵심 기능 완전 불가, 데이터 유실 | 결제 후 예약 미생성, 중복 결제 |
| Major | 주요 기능 오동작, 우회 가능 | 알림 미발송, 랭킹 오계산 |
| Minor | 부가 기능 오류, UX 문제 | 텍스트 오탈자, 정렬 이상 |

## 도메인별 핵심 테스트 경로

### 예약 골든 패스
1. 로그인 → 미용사 검색 → 서비스 선택 → 날짜/시간 선택
2. 예약 확정 → 결제(토스) → 예약 완료
3. 채팅방 자동 생성 확인
4. 미용사·고객 양쪽 SSE 알림 수신 확인

### 동시성 테스트
- 같은 시간대 예약 2건 동시 요청 → 1건 성공, 1건 409
- k6 스크립트: `scripts/k6_reservation.js`

### 결제 상태 전환
- PENDING → (10분 경과) → 자동 삭제
- PENDING → PAID → REFUNDED (순서 외 전환 시 400)
